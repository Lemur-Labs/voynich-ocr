## What a pass means

- A pass rules out a uniform miss of 0.05 or more per level, not 0.04.
- ECE can't see cancelling errors within a bin.
- The disputed stratum is descriptive.

This run did not pass. A8's minimum counts rendered glyphs, and every level clears it. ECE, though, is computed on
recognized glyphs: level 2 has 2,309, fewer than 3,000, where ECE's upward bias grows. The failure does not rest on
that bias, because every lower bound (0.120 to 0.162) is itself far above 0.05.
