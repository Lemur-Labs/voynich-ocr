## Interpretations made in code (G1-6)

- **`unscorable` class:** a column left with fewer than 2 contributing sources after the mask. It used to be
  `agree`. Excluded from gated sets.
- **`!` loci:** text not in the manuscript (IVTFF 2.0.1), so excluded, as `ivtt` does.
- **ZL's `?`:** ZL is the base sequence, so its `?` is a literal column; wildcards apply from the second source on.
- **Leftover `?`:** a wildcard covering fewer columns than it has leaves the rest out. Reported per source: IT 48,
  FG 29, GC 11, CD 6, ZL 0.
- **`zl_uncertain`:** covers ZL's first-option glyphs and ZL gaps next to them. An empty first option (`[:A2]`, 3 in
  ZL) flags its neighbour.
- **Granularity:** the column holds a gap and exactly one other reading, and one side is only CD and/or FG.
- **Expressible codes:** taken from each source's whole level-0 file, test pages included (the frozen text says
  "file").
- **Word breaks:** `<->` and `<~>` count as `.`, and a boundary with any `,` is `uncertain`.
- **Section rates:** computed on loci all four fixed sources cover.
